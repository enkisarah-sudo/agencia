# Project Knowledge System

## Resumen ejecutivo
Este repositorio organiza la estrategia integral para operar y escalar una productora de contenido adulto con base en Paraguay y enfoque global. La documentación está diseñada para pasar de idea a ejecución con gobernanza, métricas y ciclos de aprendizaje.

## Cómo navegar
1. Leer `00_master_strategy.md` para la visión general.
2. Ejecutar trabajo por dominios `01` a `09`.
3. Usar los archivos `*_operating_system.md` y `*_templates.md` como guías operativas.

## Principios de ejecución
- Enfoque por mercados (USA / Europa / Asia).
- Priorización por unit economics y riesgo.
- Compliance-by-design y seguridad de datos.
- Experimentación continua con ciclos quincenales.

## Cadencia sugerida
- **Diario**: operación comercial y soporte.
- **Semanal**: revisión de KPIs, pricing y embudos.
- **Mensual**: roadmap, budget y expansión por mercado.

## Conclusiones prácticas
La documentación está diseñada para que un equipo pequeño pueda ejecutar como una organización global: foco en procesos, estándares y decisiones basadas en datos.
